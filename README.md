# 🇩🇪 دليل استخدام منصة Deutsch Meister (منصة تعلّم الألمانية)

مرحباً بك في منصة **Deutsch Meister** — موقع تعليمي تفاعلي ثابت (Static Web App) مبني خصيصاً للمتعلم العربي لمراجعة وإتقان المستويين A1 و A2 والتحضير لـ B1 و Ausbildung في ألمانيا.

---

## 🚀 كيفية تشغيل الموقع

### الطريقة 1: التشغيل المباشر بدون إنترنت (الأسهل)
1. افتح المجلد `website/`.
2. انقر نقراً مزدوجاً (Double Click) على ملف `index.html`.
3. سيعمل الموقع مباشرة في أي متصفح (Edge, Chrome, Firefox) بجميع ميزاته وبدون الحاجة لأي اتصال بالإنترنت أو تثبيت برامج!

### الطريقة 2: التشغيل عبر خادم محلي (Localhost)
إذا كنت تفضل بيئة الخادم المحلي:
```bash
node website/serve.js
```
ثم افتح الرابط: **http://localhost:3000/**

## ➕ كيفية إضافة درس جديد دون لمس الكود

1. أنشئ ملفاً جديداً في مجلد المستوى المناسب، مثلاً:
   `website/data/lessons/a2-1/31-mein-neuer-unterricht.js`

2. ضع في الملف الهيكل القياسي التالي:
```javascript
window.LESSONS = window.LESSONS || {};

    { type: "rule", content: "قاعدة ذهبية للحفظ." },
```

## 💾 النسخ الاحتياطي واستعادة التقدم (Backup & Restore)

- يتم حفظ جميع بياناتك (الدروس المكتملة، الدرجات، نقاط XP، سلسلة المذاكرة اليومية Streak، وسجل الأخطاء) تلقائياً في ذاكرة المتصفح المحلية (`localStorage`).
- **لتصدير تقدمك:**
  1. افتح صفحة **لوحة التقدم** (`#/progress`).
  2. اضغط على زر **"تصدير نسخة احتياطية (JSON)"**.
  3. سيتم تنزيل ملف باسم `deutsch-meister-backup-YYYY-MM-DD.json`.
- **لاستعادة تقدمك على جهاز آخر أو متصفح آخر:**
  1. اضغط على زر **"استيراد تقدم محفوظ"** في نفس الصفحة.
  2. اختر ملف النسخة الاحتياطية.
  3. سيتم استرجاع كل درجاتك وأخطائك ونقاط خبرتك فوراً!

## 🎮 الألعاب التعليمية المتاحة في المنصة

1. **تحدي أدوات التعريف (der / die / das):**
   - سباق 45 ثانية لاختيار الأداة الصحيحة للاسم وفق كود الألوان (der = أزرق، die = أحمر، das = أخضر).
2. **تحدي الماضي التام (haben oder sein?):**
   - تمييز الأفعال التي تأخذ `ist` (أفعال الحركة وتغير الحالة) عن بقية الأفعال التي تأخذ `hat`.
3. **سباق الماضي البسيط (Präteritum Sprint):**
   - اختبار سريع للأفعال الشاذة والأساسية المعتمدة في امتحانات A2 و B1.
4. **تحدي الإعراب الألماني (Kasus Trainer):**
   - إتقان حالات Akkusativ و Dativ و Genitiv وحروف الجر المشتركة (Wechselpräpositionen).
5. **جدول تصريف الأفعال الشامل (Verbtabelle A1 – B1):**
   - جدول يحاكي دفتر الملاحظات اليدوي (المصدر - الماضي البسيط - المساعد - اسم المفعول - المعنى العربي بكلمة واحدة) مع بحث فوري واستماع صوتي وفلاتر حسب المستوى والفعل المساعد.

## 🔊 محرك الصوت الذكي (AI Voice Settings)

تم تجهيز الموقع بمحرك صوتي ذكي يستبعد تماماً أصوات مترجم قوقل الروبوتية القديمة:
1. **الوضع الافتراضي (مجاني 100% وبدون أي API):**
   - يختار تلقائياً الأصوات العصبية البشرية (Neural / Natural Voices مثل `Microsoft Katja` و `Conrad` في Edge و Windows).
   - أصوات طبيعية وواقعية جداً لا تتطلب أي مفتاح أو اشتراك.
2. **وضع الذكاء الاصطناعي الفائق (OpenAI TTS):**
   - اضغط على زر 🔊 (إعدادات الصوت) في الشريط العلوي.
   - يمكنك إدخال مفتاح **OpenAI API Key** الخاص بك (`sk-...`) واختيار الصوت الذي يعجبك (`Nova`، `Onyx`، `Alloy`).
   - جودة استوديو خارقة للعادة ونطق ألماني احترافي.
   - المفتاح يُحفظ محلياً فقط في جهازك ولا يُرسل لأي جهة.
3. **وضع الملفات الصوتية المولّدة مسبقاً (Pre-generated MP3s via edge-tts):**
   - يدعم الموقع تشغيل ملفات MP3 عالية الجودة مخزنة محلياً في مجلد `website/audio/` عبر `manifest.js` دون الحاجة لأي إنترنت على الإطلاق.
   - لتوليد ملفات الصوت لجميع الدروس والأفعال والمفردات:
     1. ثبّت بايثون على ويندوز من [python.org](https://www.python.org/) مع تفعيل خيار `Add python.exe to PATH`.
     2. افتح موجه الأوامر (Terminal) وثبّت مكتبة `edge-tts` المجانية:
        ```bash
        pip install edge-tts
        ```
     3. شغّل أداة التوليد التلقائي:
        ```bash
        python tools/generate_audio.py
        ```
     4. ستقوم الأداة بمسح كل ملفات الدروس والمفردات، وتوليد ملفات MP3 بنبرة طبيعية (`de-DE-KatjaNeural` بصوت هادئ ومناسب للتعلم -10%)، وتحديث ملف الفهرس `website/audio/manifest.js` تلقائياً!
     - إجمالي الملفات الصوتية: حوالي **2,129 ملف صوتي** بحجم إجمالي تقريبي **~52 ميغابايت**.
